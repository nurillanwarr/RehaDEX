# Kepentingan dan Tujuan

## Kepentingan
Menyatukan data pasien, data IoT, dan hasil pemeriksaan sehingga 20 pengukuran dalam satu sesi dapat dipantau dari satu dashboard.

## Tujuan
1. Menyimpan profil pasien.
2. Membuat sesi pemeriksaan.
3. Menerima data ESP32 melalui Wi-Fi.
4. Menyimpan 20 pengukuran per sesi.
5. Menampilkan data terbaru dan riwayat.
6. Menampilkan grafik/perkembangan pada tahap berikutnya.
7. Menjadi fondasi untuk analitik setelah dataset cukup.

## Batasan
MVP tidak melakukan diagnosis atau keputusan medis otomatis.
