# Keamanan dan Privasi

Data pasien perlu diperlakukan sebagai data sensitif.

Minimum:
- gunakan ID pasien internal
- jangan taruh password database di source code
- gunakan `.env`
- batasi akses dashboard
- validasi data ESP32
- jangan membuka backend ke internet tanpa perlindungan
- gunakan HTTPS/authentication saat deployment

Sistem ini adalah prototipe akademik dan bukan alat diagnosis medis.
