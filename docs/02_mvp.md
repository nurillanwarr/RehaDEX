# MVP

Fitur wajib:
- Tambah pasien.
- Buat sesi pemeriksaan.
- Target 20 pengukuran.
- Status ESP32.
- Menerima data IoT.
- Menyimpan timestamp dan nomor pengukuran.
- Tabel riwayat 1–20.
- Dashboard data terakhir.

Kriteria selesai:
1. ESP32 tersambung Wi-Fi.
2. ESP32 mengirim 1 data.
3. Backend menerima.
4. Data tersimpan.
5. Website menampilkan.
6. Data dapat dikirim sampai 20 kali.
7. Data tidak tertukar antar pasien/sesi.
